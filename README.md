Rust, C#, C++ をごちゃ混ぜにしたようなインタプリタ言語です。

## Build and Hello World:
Create source file as `source.fr`
```
println("Hello, World!");
```

build and run.
```
$ make release -j
$ ./fire source.fr
```

(debug-build)
```
$ make debug -j
```
